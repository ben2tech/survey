# ⭐ ติดตั้งแบบ Workers (ใช้ถ้าโปรเจกต์ลงท้าย .workers.dev)
โครงสร้างไฟล์ใน GitHub ต้องเป็นแบบนี้ (หน้าเว็บอยู่ใน `public/` เพื่อไม่ให้ไฟล์ SQL/โค้ดถูกเปิดดูจากภายนอก)
```https://survey.ben2tach.workers.dev/admin
wrangler.jsonc
worker.js
public/index.html
public/admin.html
functions/api/*.js
schema.sql  schema_v2.sql  README.md
```
1. Cloudflare → Storage & Databases → **D1** → Create database ชื่อ `survey-db` → Console → วางเนื้อหา `schema.sql` แล้ว Run
2. หน้า D1 ของฐานข้อมูลนี้ คัดลอก **Database ID** ไปแทนข้อความ `วาง-DATABASE-ID-ของ-D1-ตรงนี้` ใน `wrangler.jsonc` (ชื่อ `name` ต้องตรงกับชื่อ Worker เดิม)
3. Commit ไฟล์ทั้งหมดขึ้น GitHub (ลบ `index.html`/`admin.html` ที่อยู่นอก `public/` ออก) → Cloudflare Deploy ให้อัตโนมัติ
4. Worker → **Settings → Variables and Secrets** (จะเพิ่มได้หลังมีโค้ด Worker แล้ว) → Add → Type **Secret** ชื่อ `ADMIN_PASSWORD` ค่า = รหัสที่คิดเอง → Deploy
5. เปิด `https://ชื่อ.workers.dev/admin.html` กรอกรหัสเข้าสู่ระบบ
(Turnstile: ตั้ง `TURNSTILE_SITE_KEY` และ `TURNSTILE_SECRET` เป็น Secret ทั้งคู่)

# ระบบแบบสอบถามความพึงพอใจในการเรียน (Cloudflare Pages + D1)

## โครงสร้างไฟล์
```
index.html            หน้านักเรียน/ผู้ปกครอง (รหัส → แผนการเรียน → ผู้ตอบ → ทำแบบสอบถาม)
admin.html            หน้า Admin  (/admin.html)
schema.sql            สร้างตาราง + ข้อมูลตัวอย่าง (ติดตั้งใหม่)
schema_v2.sql         อัปเกรดจากเวอร์ชันก่อนหน้าโดยไม่ลบข้อมูล (รอบประเมิน/ด้าน/PDPA)
functions/api/lookup.js  ตรวจรหัสนักเรียนกับรายชื่อ
functions/api/config.js  ดึงแผน/คำถาม
functions/api/submit.js  บันทึกคำตอบ
functions/api/admin.js   API ฝั่งผู้ดูแล (ต้องมีรหัสผ่าน)
```

## ติดตั้ง
1. อัปโหลดทุกไฟล์ (รวมโฟลเดอร์ `functions`) ขึ้น GitHub
2. Cloudflare → Storage & Databases → **D1** → สร้างฐานข้อมูล `survey-db` → Console → วางเนื้อหา `schema.sql` แล้ว Run
   (ถ้าเคยสร้างตารางเวอร์ชันก่อนหน้า schema นี้จะลบตารางเก่าให้)
3. Workers & Pages → Create → Pages → Connect to Git (Build command ว่าง, Output directory = `/`)
4. Pages project → **Settings → Bindings** → เพิ่ม D1 ชื่อตัวแปร `DB` = `survey-db`
5. **Settings → Variables and Secrets** → เพิ่ม `ADMIN_PASSWORD` (ชนิด Secret) = รหัสผ่านผู้ดูแล
6. Redeploy → เข้า `https://ชื่อโปรเจกต์.pages.dev/admin.html`

## หน้า Admin ทำอะไรได้
- **สรุปผล**: จำนวนผู้ตอบ (นักเรียน/ผู้ปกครอง), คะแนนเฉลี่ยรวมและระดับความพึงพอใจ, สรุปรายแผน, ค่าเฉลี่ย+การกระจายคะแนนรายข้อ, กราฟจำนวนผู้ตอบรายวัน, ข้อเสนอแนะ — กรองตามแผน/ผู้ตอบได้
- **แผนการเรียน**: เพิ่ม/แก้ชื่อ/เปิด-ปิด
- **คำถาม**: เพิ่ม/แก้/ปิดใช้งาน กำหนดให้ใช้กับทุกแผนหรือเฉพาะแผน และเฉพาะนักเรียน/ผู้ปกครอง/ทั้งสอง
- **ข้อมูลผู้ตอบ**: ดูรายการ, ลบรายการ (ให้ตอบใหม่ได้), ส่งออก CSV (เปิดใน Excel ได้), ล้างข้อมูลเมื่อขึ้นรอบใหม่
- **ตั้งค่า**: เปิด/ปิดรับแบบสอบถาม, แก้ชื่อแบบสอบถาม

เกณฑ์แปลผลค่าเฉลี่ย: 4.51–5.00 มากที่สุด · 3.51–4.50 มาก · 2.51–3.50 ปานกลาง · 1.51–2.50 น้อย · 1.00–1.50 น้อยที่สุด

## ระบบรายชื่อนักเรียน (CSV)
แท็บ **รายชื่อนักเรียน** ใน admin
- นำเข้า CSV คอลัมน์ `รหัสนักเรียน, ชื่อ-สกุล, ห้อง, แผนการเรียน` (กดดาวน์โหลดไฟล์ตัวอย่างได้) รองรับ UTF-8 และ CSV ภาษาไทยจาก Excel; รหัสซ้ำ = อัปเดตทับ; แถวที่ผิดจะถูกข้ามและแจ้งเลขแถว
- ถ้าระบุแผนในไฟล์ เมื่อนักเรียนกรอกรหัสระบบจะ **ล็อกแผนตามรายชื่อ** อัตโนมัติ (เว้นว่าง = ให้เลือกเอง)
- ตั้งค่า → "รับเฉพาะรหัสนักเรียนที่อยู่ในรายชื่อ" เพื่อกันรหัสแปลกปลอม
- รายชื่อแสดงสถานะ นักเรียน/ผู้ปกครองตอบแล้วหรือยัง กรอง "ยังไม่ตอบ" และส่งออก CSV เพื่อติดตามได้
- หน้าสรุปผลมี **อัตราการตอบ (%) รายแผน** เทียบกับรายชื่อ

## รอบการประเมิน
แท็บ **รอบการประเมิน** — สร้างรอบใหม่ทุกภาคเรียน (ระบบตั้งเป็นรอบปัจจุบัน นักเรียนทุกคนตอบใหม่ได้), ปิด/เปิดรับแยกรอบ, เปลี่ยนชื่อ, ลบรอบที่ยังไม่มีข้อมูล
ตัวเลือก "รอบการประเมิน" ที่มุมขวาบนใช้ดูสรุปผล/ข้อมูล/สถานะการตอบของรอบใดก็ได้ และหน้าสรุปผลมีตาราง **แนวโน้มข้ามรอบ**
ปุ่ม "ล้างข้อมูลรอบนี้" ลบเฉพาะรอบที่เลือก

## ด้านของคำถาม และสรุปรายห้อง
- แท็บ **คำถาม** → การ์ด "ด้านของคำถาม" เพิ่ม/เรียงลำดับด้าน แล้วกำหนดด้านให้แต่ละคำถาม (หน้านักเรียนจะแสดงหัวข้อด้าน)
- หน้าสรุปผลมี สรุปรายด้าน, สรุปรายห้อง (ห้องมาจากไฟล์รายชื่อ), ตัวกรองห้อง
- คำถามเดิมที่อัปเกรดมาจะยังไม่มีด้าน ให้เข้าไปกำหนดเอง

## พิมพ์รายงาน / PDF
หน้าสรุปผล → ปุ่ม "🖨️ พิมพ์รายงาน / บันทึก PDF" → เลือก Save as PDF (หัวรายงานแสดงรอบ ตัวกรอง วันที่ และเกณฑ์แปลผลอัตโนมัติ)

## ความปลอดภัย
1. **Turnstile (กันบอท)** — Cloudflare → Turnstile → Add widget (โดเมน *.pages.dev หรือโดเมนของโรงเรียน) แล้วที่ Pages → Settings → Variables and Secrets เพิ่ม
   `TURNSTILE_SITE_KEY` (Plaintext) และ `TURNSTILE_SECRET` (Secret) → Redeploy ถ้าไม่ตั้ง ระบบจะไม่ใช้ Turnstile
2. **Cloudflare Access (ครอบหน้า admin)** — Zero Trust → Access → Applications → Self-hosted → เพิ่ม path `admin.html` และ `api/admin*` (ใช้ one-time PIN ทางอีเมลโรงเรียน) ทำให้มี 2 ชั้น: อีเมล + ADMIN_PASSWORD
3. **Rate Limiting** — Security → WAF → Rate limiting rules: path `/api/lookup` และ `/api/submit` เช่น 20 ครั้ง/นาที/IP

## ประกาศความเป็นส่วนตัว (PDPA)
แท็บ ตั้งค่า → แก้ข้อความประกาศ และเลือกบังคับกดยินยอมหรือไม่ (หน้าแรกของนักเรียนจะแสดงประกาศ + ช่องติ๊กยินยอม)
ข้อความเป็นแม่แบบ ควรให้ผู้รับผิดชอบด้านข้อมูลส่วนบุคคลของโรงเรียนตรวจทาน โดยเฉพาะเรื่องความยินยอมของผู้เยาว์ และกำหนดระยะเวลาเก็บข้อมูล

## นำเข้ารายชื่อ (รูปแบบ Excel ของโรงเรียน)
คอลัมน์: `รหัสนักเรียน, คำนำหน้า, ชื่อ, นามสกุล, สาย/แผนการเรียน, ชั้น, ห้อง, เลขที่` ระบบอ่านจากหัวคอลัมน์ในแถวแรก (ลำดับคอลัมน์ไม่สำคัญ)
- เลือกได้หลายไฟล์พร้อมกัน และอัปโหลด `.xlsx` ได้ทุกชีตในครั้งเดียว (ถ้าชีตไม่มีคอลัมน์สาย จะใช้ชื่อชีตเป็นสาย)
- ชื่อที่แสดง = คำนำหน้า+ชื่อ นามสกุล, ห้องที่แสดง = ม.{ชั้น}/{ห้อง}
- ถ้าติดตั้งไว้ก่อนหน้านี้ ให้รัน `schema_v3.sql` ใน D1 Console ครั้งเดียว (เพิ่มคอลัมน์ใหม่ ไม่ลบข้อมูล)
